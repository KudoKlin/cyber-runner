# Тестовый файл изменений

Этот файл создан для проверки видимости изменений.

## Что было сделано в игре CYBER RUNNER 2077

### 1. Механика подката (slide)
- Новый тип движения: игрок пригибается, хитбокс уменьшается
- Управление: свайп вниз (мобильные), стрелка вниз / S (клавиатура)
- Воздушные препятствия «балки» проходятся только подкатом

### 2. Очки заменены на расстояние
- Вместо «очков» отображается пройденное расстояние в метрах
- Биомы меняются каждые 300 м
- Скорость растёт каждые 250 м
- Достижения и задания измеряются в метрах

### 3. Новые препятствия
- Балки (верхние), требующие подката
- Двойные препятствия на высокой скорости

## Статус
Изменения находятся в файле `index.html` в рабочей ветке.
