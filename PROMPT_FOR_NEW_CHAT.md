# Промпт для нового чата (продолжение работы над Cyber Runner)

## Контекст
Проект: https://github.com/KudoKlin/cyber-runner — киберпанк-раннер (PWA, один index.html).
В main на GitHub лежит версия с distanceM и подкатом, НО без новой музыки.
Локальные изменения (новая музыка + тестовый файл) не были запушены из-за отсутствия
доступа к push в прошлой сессии.

## Файлы для переноса (приложить к сообщению)
1. `index.html` (md5 f1043d5c61fe8d21cad7d4d9c175eb07, 127417 байт) — полная версия:
   - расстояние вместо очков (distanceM, метры в HUD/Game Over/рекордах)
   - механика подката (slide) + воздушные балки (тип 'bar')
   - новая фоновая музыка: секвенсор Web Audio API, 10 треков-оммажей
     (NEON DISTRICT, KOIN TOSS, HYRULE LEGEND, STORK DRIFT, RIVER OF TIME,
     PASTEL DUSK, FOG ALLEY, RIP AND TEAR, ASCENDANT, BLOCK DRIVE),
     баннер NOW PLAYING, автоматическая смена трека по BPM
2. `sw.js` (md5 b25c587abc4a73398382bb8ffbd7b273) — кэш cyber-runner-v6
3. `CHANGES_TEST_RENAMED.md` (md5 a1b9f030bb17c082365fc04621c7bee0) — тест публикации

## Задачи для нового чата (по порядку)
1. Клонируй репозиторий KudoKlin/cyber-runner, сравни main с приложенными файлами
   (`git diff`, `grep distanceM index.html`).
2. Замени index.html и sw.js на приложенные версии, сделай коммит и PUSH в main
   (проверить credentials: ssh -T git@github.com или HTTPS PAT).
3. Удали CHANGES_TEST*.md финальным коммитом (договорённость из прошлой сессии).
4. Проверь на GitHub Pages после деплоя: игра, музыка (переключение треков), подкат.
5. Дальнейшие улучшения по приоритету:
   - dash (рывок с кулдауном), двойной прыжок
   - streak + ежедневный challenge, расходники в магазине
   - объектный пулинг, swept-collision (коллизии на высокой скорости)
   - онлайн-лидерборд, туториал при первом запуске

## Важные правила
- После каждого этапа сразу пушить/публиковать — локальный workspace ненадёжен
  (в прошлой сессии контейнер был пересоздан и файлы потерялись).
- Музыка должна оставаться royalty-free: только нотная запись/Web Audio,
  никаких загруженных аудиофайлов из игр.
